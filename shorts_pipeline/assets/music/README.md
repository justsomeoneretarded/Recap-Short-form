# Music library

Put royalty-free tracks that allow commercial use in one folder per mood:

    tense/  action/  dark/  sad/  mysterious/  triumphant/

(.mp3, .wav, .m4a, .ogg or .flac). Each Short picks a track for the mood Gemini gave its script,
looped to length, faded, and ducked automatically under the narrator and movie lines. Keep the
licence of every track in a `LICENSES.txt` next to it. Without tracks for a mood, the Short has no
music bed (the review says so).
